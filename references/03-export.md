# 流程三：Markdown＋截图 → HTML／PDF

输入：流程二完成的 `图文讲义.md`、对应截图、可选校对记录。Markdown 是唯一正文来源；导出时不得重新解释视频、概括正文、增补例子或修改论证。

## A. HTML（已实现）

1. 读取完整 Markdown，检查图片相对路径存在。保持标题、时间范围、正文、公式和截图的原顺序。
2. 应用 `assets/lecture.css`：浅色页面、白底正文、目录、清晰标题和段落、原比例截图。时间保留为普通文字，可保留目录跳转和点击查看原图。
3. 用随附 KaTeX 预排版 TeX 公式：行内变量和分数用数学字体；独立公式自然居中、字号贴近正文，无底色、边框、圆角或公式卡片。
4. 字体和公式 CSS 内嵌，离线可读，不依赖 CDN 或打开时执行 JavaScript。图片仍为相对路径，除非用户另行要求单文件版；不能把字体内嵌说成图片也已内嵌。
5. 核对内容与 Markdown 一致、截图齐全、时间没有跳转链接、公式没有错误。预览首页、正文、公式、末尾及窄窗口效果。浏览器权限阻止预览时不绕过限制，如实说明核对范围。

运行：

```bash
python3 SKILL_DIR/scripts/render_html.py '项目目录/图文讲义.md' --node /实际路径/node
```

`SKILL_DIR` 为实际技能目录。Node.js 在 PATH 内时可省略 `--node`；无公式时不需要 Node.js。默认在 Markdown 同目录生成同名 `.html`，更新已有输出时加 `--overwrite`。脚本只读 Markdown，不改写 Markdown 或 PDF。

辅助渲染器支持此流程使用的 Markdown 子集：标题、普通段落、单独时间文字、独立图片行、链接、加粗／斜体和 TeX。若存在列表、表格、代码块等其他结构，先采用可靠方式扩展并验证，不静默丢弃或假装已经正确排版。

交付 HTML 的本地链接。传到其他设备时，HTML 与图片目录一起传；只有实际内嵌全部图片后才能称为单文件。

## B. PDF（已实现）

默认输入仍是流程二完成的 Markdown 和截图。使用与 HTML 相同的正文渲染函数，在内存中生成中间 HTML，不覆盖已有 HTML，也不重新解释正文。用户明确要求从已有 HTML 转 PDF 时，可直接输入本技能导出的离线 HTML；此时以该 HTML 快照为准，不暗示已经重新核对 Markdown。

```bash
PYTHON SKILL_DIR/scripts/render_pdf.py '项目目录/图文讲义.md' \
  --output '输出目录/图文讲义.pdf' --node /实际路径/node
```

也可将输入改为同项目的“图文讲义.html”。--output 可省略，默认同目录同名 PDF；已有文件或检查报告时需明确 --overwrite。在当前工作区交付成果放在 output/pdf/，测试版先另取名称保留旧版。仅用户请求 PDF 时运行，不把 PDF 强加为默认交付。

### 环境与排版

复用现有环境；缺少时用隔离环境安装已验证的 weasyprint==70.0，Linux 还需 Pango 和可显示中文的字体（本机 Noto Sans CJK SC）。公式从 Markdown 导出时仍需随附 KaTeX 和 Node.js；已排好公式的 HTML 不再调用 Node.js。模型、虚拟环境和系统字体不复制进技能目录，不假设 /tmp 环境永久存在。

离线排版不调用浏览器、不执行 JavaScript，仅允许讲义目录内的文件和 data 资源。缺图、远程资源、公式错误、图片数量不一致或字号仍被网页样式覆盖时应停止，不能悄悄交付缺内容的 PDF。

默认 A4，左右 15mm、上 16mm、下 18mm，正文 11 磅、1.62 倍行高。可用 --font-size 按用户需要调整；不要单纯追求最少页数。assets/lecture-print.css 必须作为最后的 author 样式插入文档，不能误用低优先级用户样式——旧转换曾因此实际采用网页的 13.5 磅，而非指定的 11 磅。

打印隐藏网页目录，保留 PDF 章节书签和页码；标题、时间与后续文字避免孤立。截图按原比例、最大可打印宽度显示，图与图注一起分页，长图限制到页内且不变形。不删正文、不重排论证和截图顺序，不把低分辨率图强行放大；图注可移入对应 figure 以绑定分页。复杂代码看不清时保留问题并调整版式或另加经确认的局部图，不悄悄裁去原片信息。

### 验证与交付

脚本生成 PDF 及同名“.检查.json”，记录源指纹、页数、实际字号、图片放置数、可能越界和稀疏页。脚本用当前已验证 WeasyPrint 的布局树辅助检查，升级渲染器时应重跑 tests/test_pdf_export.py；报告不能代替 PDF 自身核验。

用 pypdf/pdfplumber 核对可提取正文、章节、数值、公式、书签、A4 尺寸与图片实际绘制次数。不要把每页共享资源字典中的全部图片都算成该页已绘制图片。与旧版比较时排除页码和图注的跨页提取顺序差异，单独核对图注与正文，不能因此忽略真正缺句。

将最终 PDF 用 pdftoppm 渲染为 PNG，查看全部页面缩略图，并放大首页、正文、公式、代码截图、跨页处与末尾。检查乱码、裁切、遮挡、孤立标题/图注、无意义空白页；修改后重看最新输出。稀疏页只是提示，不能靠删内容或把图压到看不清来消除。

机器生成报告的 visual_review_completed 默认 false；实际完成页面查看后另存“PDF验收记录”描述检查范围与局限，不能自动把它翻成已验收。正文覆盖与听音结论沿用流程二，PDF 排版成功不能把未决内容变成正确。

交付独立 PDF 的本地链接；图片和字体实际包含在 PDF 内，不需要读者另带图片目录。保持 Markdown、HTML 和原始材料不变。
