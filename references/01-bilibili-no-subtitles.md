# B 站无平台字幕：本地语音转写

输入：视频链接或本地音视频。先按有字幕分支排除未登录、接口失败等情况；确认目标视频实际无平台字幕。弹幕不是字幕，画面压制字幕也不等于可下载字幕轨。

输出：本地视频、ASR 原稿、规范字幕时间轴、SRT、文字稿、转写来源与参数。规范 JSON 与平台字幕分支同为 `segments: [{id,start,end,text}]`，可进入流程二。不要把 ASR 标成人工字幕或已校对字幕。

## 准备与模型选择

复用[有字幕分支](01-bilibili-subtitled.md)的视频下载与音画流验证。MP3、WAV、含音轨的 MP4 均可直接输入；无需先转成有损 MP3。需要裁剪时可用 FFmpeg 导出 16kHz 单声道 PCM WAV。

优先复用 Python 环境和模型缓存。新建隔离环境时安装 faster-whisper；已验证组合为 faster-whisper 1.2.1、av 16.1.0。av 19.0.1 曾因 metadata_errors 参数与该版 faster-whisper 不兼容，遇到该错误固定兼容版本，不修改系统 Python。模型首次下载需要联网；缓存完整后用 --offline 运行，不上传音频。

CPU 可从 large-v3-turbo、INT8、8 线程开始，根据资源和样本调整；用时和内存占用不能当作所有设备的固定要求。中文不要选 .en 模型。GPU 仅在设备和运行库实际可用时启用，不能由 CPU 名称推定核显加速可用。

实测中 small 很快但中文错字较多；turbo 适合初稿；medium 可用于疑点复核，但更大模型并非每个词都更准，同一模型也会随上下文改变输出。语言未知时先自动识别并核对；任务用 transcribe，不误用翻译任务。领域术语提示可选，只提供主题或术语，不把参考字幕全文作为提示后宣称识别准确。

## 连续转写并保存来源

```bash
PYTHON SKILL_DIR/scripts/transcribe_local.py '视频.mp4' \
  --output-dir '项目目录/识别原稿' \
  --model large-v3-turbo --device cpu --compute-type int8 --threads 8 \
  --download-root '模型缓存目录' --offline --word-timestamps
```

替换 PYTHON、SKILL_DIR 为实际路径；首次下载模型时省略 --offline。语言可用 --language zh 指定；不指定时自动识别。只有已知术语才加 --prompt。脚本默认不覆盖同名结果；复核另设目录并显式选择 medium 等模型。

输出“字幕-ASR原始.json”（含置信相关字段及可选词时间）、“字幕-规范.json”、“字幕-ASR.srt”、“字幕-ASR.txt”、“字幕-ASR-带时间.txt”、“转写来源.json”。来源记录模型、版本、语言、参数、音轨时长、耗时、内存、时间戳异常及未完成听音状态。模型、虚拟环境独立存放，不复制进技能包，不依赖临时目录在下次仍存在。

## 覆盖、对齐与复核

转写后先按[疑点复核与讲解点覆盖](quality-review.md)运行 review_asr.py。保留候选清单，只对选定的含前后文窗口做第二模型复核，不自动重跑全片、不自动改稿。

- 正式材料优先连续全片转写。短样本只用于选型；一分钟截断曾造成尾部完整句缺失，而连续全片恢复了这些句子。必须分块时保留上下文重叠、实际时间偏移和去重记录，不按无重叠定长片段硬拼，不把边缘残句当作稳定漏句。
- 检查首末时间、顺序、越界、重叠、异常长段、重复文本及静音／音乐附近的臆造。VAD 只是辅助，时间空隙不能单凭长度判为漏句。
- 时间戳是估计。词时间可辅助断句；精确字幕仍需对齐和听音抽查。重新断句不改原始 JSON，不悄悄补词或编造时间。
- 学科术语、数字、公式、否定词、疑似漏句与模型分歧优先结合画面和音频复核。必要时用 medium 识别包含前后文的片段，保留绝对起止时间；第二模型是独立证据，不是答案。
- 原始识别稿不覆盖；校正稿和依据另存。没有人工听写真值时不报告准确率，没有逐句听音时如实说明。无法确认的词在讲义及校对记录标注，不猜写。

材料齐全后仅在用户要求讲义时进入[流程二](02-write-markdown.md)。公式、代码和图示仍需截图核对，ASR 成功不能替代内容检查。
